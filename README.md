# 🔍 Customer Churn Analysis
### Telco Customer Churn Analysis using SQL, Python & Tableau

---

## 📌 Project Overview
This project analyzes **IBM Telco Customer Churn dataset** to identify 
why customers leave and which factors contribute most to churn.
The analysis covers end-to-end data analytics workflow using 
**SQL, Python, and Tableau**.

---

## 📊 Dataset
| Detail | Info |
|--------|------|
| **Source** | IBM Telco Customer Churn (Kaggle) |
| **Rows** | 7,043 customers |
| **Columns** | 21 features |
| **Target Column** | Churn (Yes/No) |
| **Churn Rate** | 26.5% |

## 🗄️ SQL Analysis
**10 Queries Covered:**
| # | Query | Insight |
|---|-------|---------|
| 1 | Total Customers & Churn Count | 1,869 customers churned |
| 2 | Churn Rate % | 26.5% overall churn |
| 3 | Churn by Gender | Almost equal — Male vs Female |
| 4 | Churn by Contract | Month-to-month = highest churn |
| 5 | Churn by Internet Service | Fiber optic = highest churn |
| 6 | Avg Monthly Charges | Churned customers pay more |
| 7 | Churn by Payment Method | Electronic check = highest risk |
| 8 | Senior Citizen Churn | Seniors churn 41% vs 24% |
| 9 | Churn by Tenure Group | New customers churn most |
| 10 | High Risk Customers | Month-to-month + High charges |

## 💡 Business Recommendations
1. **Offer long-term contracts** — discourage month-to-month
2. **Target Fiber Optic users** — special retention offers
3. **Focus on new customers** — first year is critical
4. **Auto-payment incentives** — reduce electronic check usage
5. **Senior citizen programs** — special discounts/support
